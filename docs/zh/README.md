# 中文参考版

这个目录是 `docs/` 下日文文档的中文对照版，**仅供自己理解和思考用**。

- **提交给 DevOps Camp 的正本是 `docs/` 下的日文版**，两边内容不一致时以日文版为准。
- 表名、列名、API 路径、`event_type` 取值等**标识符一律保持原样不翻译**，避免和代码对不上。
- 日文技术术语（名寄せ / 正規化 / サブスク 等）在首次出现时给出中文，之后沿用日文原词。
